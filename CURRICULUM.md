# Academy curriculum (plan and status, 2026-11-25)

Every lesson follows one format (src/ui/lesson.tsx): introduction → definition → explanation → rule → formula with meaning of
each symbol → why it works → worked examples step by step (with an alternative way) → exceptions → typical mistakes →
"try it" task → practical use → **teaching method for children** → summary → mastery check (≥ 80 %).
Every check question explains each wrong option, the rule, the step-by-step solution and links back to the lesson.

Language courses are written separately for uz and ru (not translated). Math, pedagogy, psychology and reading have
equal content in both languages.

## Planned modules (target ~300–450 lessons per learning track; built in batches)

antonim, omonim, paronim, frazeologizm) · morfemika va so'z yasalishi · morfologiya (ot, sifat, son, olmosh, fe'l va

undalma, qo'shma gap) · imlo (har bir qoida alohida) · nutq madaniyati · metodika (savod o'rgatish, disgrafiya, bog'lanishli nutq).

**Русский язык (ru):** фонетика (гласные, согласные, звонкие/глухие, твёрдые/мягкие, ударение, безударные гласные, редукция,
